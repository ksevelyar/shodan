# Status panel

## Requirements

* A status panel appears on the bottom line of the console.
* The left side displays sent tokens, received tokens, and cache hits.
* The right side displays the provider, model name, thinking level, and response time.
* Cache hits are displayed as a percentage.

## User scenarios

### 1. User views session statistics

* User sends a message and receives a response with usage data.
* User sees sent tokens, received tokens, and cache-hit percentage on the left of the bottom panel.
* User sees the provider, model name, thinking level, and response time on the right.
* User scrolls the conversation. The status panel remains visible.
